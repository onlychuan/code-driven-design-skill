Model rule: finished = min(capacity, previous queue + arrivals)
next queue = previous queue + arrivals − finished. Arrivals happen before processing within each hour. No randomness, delays, priorities, or abandoned work are modeled.

Generic, offline teaching example. SVG geometry and numerical outputs share the same model; no API, account, or external asset is used.
