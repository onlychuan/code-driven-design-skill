# 1.2.0

Logo and icon design are now explicit routes alongside cards and the general visual workflow.

- Brand marks, wordmarks and lockups, with actual standalone vector delivery.
- Coherent icon families with shared grid, strokes, optical weight and small-size checks.
- A generic SVG asset study with 16/20/24/32 px previews and mark/icon exports.
- Font-dependency, monochrome/reversed variant, transparent raster and accessible SVG guidance.
- Existing digital, presentation and optional print workflows remain available.

Extract the ZIP and use `install.cmd` on Windows or `bash install.sh` on macOS/Linux. For an existing skill, use `-Force` / `--force`; the previous version is preserved outside skill discovery.

# 1.1.0

Code-driven Design is now a general visual-design workflow, with print as one optional route.

- Responsive websites, landing pages, interface screens and component prototypes.
- Diagrams, infographics, interactive explanations, small tools and simulations.
- HTML presentations and brand visuals, alongside the existing print-collateral workflow.
- Shared design tokens, structured content and real state/interaction instead of a universal millimetre scene.
- Two standalone digital examples: an interactive interface and a mechanism explainer.
- Screen-specific verification and routing to specialist final-format tools when needed.
- Existing print renderer and exact-file/CSP preservation remain available.
- Update backups are kept outside the skill-discovery directory to avoid duplicate skill entries.

Download and extract the ZIP, then double-click `install.cmd` on Windows or run `bash install.sh` on macOS/Linux. For an existing installation, use `-Force` / `--force`; the installer preserves a backup.

# 1.0.0

Initial release of Code-driven Design.

- Brand-aware HTML/CSS design and review workflow for cards, labels, posters, flyers and packaging inserts.
- Shared millimetre scene with digital color references and separate working CMYK recipes.
- HTML/SVG preview and optional vector, outlined-text CMYK PDF export.
- QR, trim, bleed, typography and physical-proof guidance.
- Exact-file publication guidance preserving sandboxed iframe, CSP and byte identity.
- Windows double-click installer plus PowerShell and macOS/Linux shell installers.
- Portable skills-only plugin manifest and optional repo marketplace.

Download the ZIP, extract it, and double-click `install.cmd` on Windows, or run `bash install.sh` on macOS/Linux. The installer copies the skill only; print runtime dependencies are optional.

The package includes generic sample artwork only. It contains no client-brand assets, private invitations, delivery addresses, proprietary fonts, credentials or Site project identifiers.
